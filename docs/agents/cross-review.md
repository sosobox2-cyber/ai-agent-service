# 교차 리뷰

요구사항과 최종 diff를 대조하고 구현 과정의 가정을 다시 확인한다. 같은 에이전트가 검토했다면 독립 리뷰로 표시하지 않는다.

- 실제 AI 경로와 모의 경로를 혼동했는가
- certain·confidence·검증과 최종 승인 계약이 유지되는가
- FULL 재추론 횟수·대상과 통신 오류 처리가 맞는가
- DTO·Schema·프롬프트·명세·화면 사이에 불일치가 있는가
- 민감정보 또는 불필요한 실제 상품 데이터가 추가됐는가
- 테스트가 기대 동작을 입증하며 미검증 범위를 정확히 보고했는가
- 사용자 변경과 범위 밖 파일이 보존됐는가

발견 사항은 심각도, 파일·위치, 근거, 재현 조건과 수정 여부를 적는다. 발견 사항이 없으면 검토 범위와 남은 한계를 적는다. 결과는 [보고서 규칙](../report/report-guide.md)을 따른다.
