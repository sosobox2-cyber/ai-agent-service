# 영향 분석

컨트롤러 → 서비스 → AI 또는 모의 추출 → 검증 → 응답을 코드로 추적한다. 실제 호출 위치를 기준으로 판단하고 클래스 이름만으로 경로를 추정하지 않는다.

- 변경 파일과 직접·간접 호출자, 요청·응답 계약과 사용자 화면의 영향
- LIGHT/FULL·Schema·파싱·프롬프트 버전의 결합
- 최종 승인, TEST_MODE, 반려 제안과 단위 설정의 회귀 가능성
- 외부 AI 전송·비용, 인증과 로그 노출의 영향
- 위험도(낮음·중간·높음)와 근거, 필요한 테스트와 미검증 범위

구현 전에 필요한 확인 사항을 분리한다. 코드 근거와 결과는 [보고서 규칙](../report/report-guide.md)에 기록한다.
