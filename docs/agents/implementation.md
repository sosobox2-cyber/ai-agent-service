# 구현

요구사항과 영향 분석에서 정한 범위 안에서 기존 계층을 유지한다. 코드·프롬프트·Schema 중 변경한 계약을 사용하는 곳을 함께 수정한다.

- 실제 AI와 모의 추출의 동작을 별도로 확인한다.
- 최종 판정과 AI 자체 판단을 섞지 않고 기존 필드·오류 의미를 유지한다.
- 프롬프트 변경은 선택·파싱·재추론·버전과 함께 검토한다.
- 운영 인증과 제한을 테스트 편의로 완화하지 않는다.
- API·화면 동작 변경 시 관련 명세·예제도 갱신한다.
- 사용자 변경과 무관한 IDE 설정·백업·생성물을 보존한다.

검증에 필요한 변경만 남기고 [테스트 검증](test-verification.md)으로 연결한다.
