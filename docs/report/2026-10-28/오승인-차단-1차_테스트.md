# 오승인 차단 1차 — 결과 한 페이지

작성일: 2026-10-28 · 단계: 테스트 · 범위: 로컬 코드·프롬프트 수정, 저장된 운영 응답 재판정

**확인된 오류 4상품·7회 응답의 오승인을 차단했다. 정상 대조군 7상품은 모두 승인을 유지했다.** 수정 프롬프트의 실제 AI 품질은 운영 반영 후 비교해야 한다.

| 평가 기준 | 오류·정상 대조군 고정, 등록 기준 오류 분리, 미사용 사례의 후속 비교 계획 |

## 검증 결과

| 검증 | 결과 |
|---|---|
| 기존 95회 이력 | 응답 있는 **93회 재판정**, 출력 잘림 2회는 제안 없어 제외 |
| 승인 변화 | **50 → 43회**. 변경된 7회는 차원 오류 2상품, 사용 인원 1상품, 모델 출처 1상품의 기존·반복 응답 |
| 정상 대조군 | 의류, 포장, 본품/사은품, 골프, 화면/모델 **7상품 모두 승인 유지** |
| Java 전체 + 패키징 | **278개 중 277 통과, 1 건너뜀, 실패·오류 0**. 실행 JAR 생성 완료 |
| 추가 AI 비용 | **$0**. 이전 확인 추정액 $0.1705084, 미측정 예약 포함 $0.3305084 유지 |

실행 환경은 Java 17.0.2와 IntelliJ 내장 Maven이다. 기본 PATH Java는 8이어서 JAVA_HOME을 지정했다. D:\maven\repository는 의존성이 부족했고, 기본 Maven 저장소에서도 POI 의존성이 부족해 최초 온라인 Maven 실행으로 해결했다. 이후 아래 전체 검증은 오프라인으로 성공했다.

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-17.0.2'
& 'D:\IntelliJ IDEA 2026.2.1\plugins\maven-plugin\lib\maven3\bin\mvn.cmd' -o '-Devaluation.replay.dir=logs/diverse-eval-20261028' package
```

초기 관련 101개 테스트 통과 후 인원 경계값을 보강하고 전체 검증을 실행했다. 건너뛴 1개는 유료 실제 AI 비교이며 이번 검증은 AI 대역·저장 제안 재생이다. 실행 로그에는 기존 로그 파일 회전 경고가 있었지만 테스트·패키징 실패는 없었다. 상세 재판정 집계는 무시된 `target/stored-proposal-replay.json`에 있다.

## 한계와 다음 단계

전체 정확도 개선율은 아직 산출할 수 없다. 이번 결과는 이미 확인한 오류에 대한 서버 차단 효과다. 계산 근거 누락·잘못된 단위 선언·미지 단위·다른 의미 오류까지 차단하지는 못하며, 충돌·혼합 구성의 프롬프트 효과는 실제 AI 재호출로 확인해야 한다. 복합 문장형 사용 인원은 추가 검토로 전환될 수 있다.
