# 허용 단위 표기 정규화 v35

작성일: 2026-10-28 · 범위: 실제 AI 응답의 단위 표기 · 위험도: 높음

## 요구사항

v34 운영 재평가에서 정상 종이 상품은 `250M`의 대소문자 차이 하나로 검토 필요가 됐다. 원문 `2박스`, `30정`이 요청의 허용 단위인 상품은 AI가 기본 단위 `개`로 표시해 검토 필요가 됐다. 원문에 없는 `1개`를 만든 수산물 상품은 계속 반려해야 한다.

## 영향분석과 변경

AI 응답 파싱 직후 기존 `CountUnitNormalizer`에서 요청이 명시한 물리 단위와 대소문자만 다른 값을 요청 표기로 맞춘다. 단일 개수 피연산자의 원문 단위가 허용 선택지에 있고 AI가 기본 단위로 표시한 경우, 출력 단위만 원문 단위로 되돌린다. 숫자·원문 근거·피연산자·confidence·certain은 바꾸지 않는다. 기존 원문 인용, 출처 충돌, 계층, 최종 승인 검사는 유지한다. 이 변경은 허용되지 않은 단위나 복수 피연산자의 계산을 자동 수정하지 않는다.
