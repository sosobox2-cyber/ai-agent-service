# 운영상품 다양성 평가 — 요구사항

- 목적: 구매옵션별로 서로 다른 실제 상품을 평가하고 프롬프트·구조 개선 우선순위를 도출한다.
- 작성일: 2026-10-28
- 단계: 요구사항
- 범위: 사용자가 지정한 Railway 운영 평가 API, 실제 AI 호출 총예산 최대 USD 1.

운영 데이터는 10,270상품, 44,898기준 행, 구매옵션 68종, 구매옵션 조합 81종이다. 같은 원본의 데이터셋이 두 개 있어 최신 등록 데이터셋을 선택했고 실행 전 백업을 확보했다. 기존 기준값·사람의 검토를 보존하며 실행 이력만 추가한다.

1차 표본 72상품은 구매옵션 68종, 조합 62종, 상위 상품군 12개를 포함한다. 숫자만 다른 상품명은 중복을 제한하고 희소 옵션·새 조합·처리 특성을 우선한다. 1차에서는 단품 8개 이하로 제한한다. 대표성 추정보다는 오류 발견을 위한 층화 탐색 표본이므로 전체 운영 정답률로 일반화하지 않는다.

완료 조건은 실제 응답·승인·비교 상태·재추론·사용량 수집, 원문 근거를 대조한 오류 유형 분석, 구매옵션별 개선 우선순위와 재검증 계획이다. 원본 등록값 일치율, 서버 승인율, 근거 검토 결과를 구분한다. 부족한 원문과 잘못된 기준값을 AI 오답으로 단정하지 않는다.

유료 호출과 운영 평가 이력 추가는 사용자 요청에 포함된다. 이번 단계의 산출물은 평가 결과와 개선 제안이다. 프롬프트 변경 효과는 변경 전후 검증 없이 주장하지 않는다.
