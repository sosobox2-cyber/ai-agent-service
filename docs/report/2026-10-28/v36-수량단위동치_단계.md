# 계산 단위와 수량 표기 동치 v36

작성일: 2026-10-28 · 범위: 실제 AI 승인 전 단위 검증 · 위험도: 높음

## 요구사항

v35 운영 평가 11건에서 정상 종이 상품의 `37m` 값과 계산 출력 `cm` 불일치, 물티슈 `70매` 원문과 허용 출력 `70매입`의 표기 차이로 정확한 제안 2건이 반려됐다. 원문이 없는 `1개` 추정과 충돌·혼합 구성은 계속 반려한다.

## 영향분석과 구현

`DIRECT` 계산의 단일 물리 피연산자, 출력값, 허용 단위가 정확히 일치하고 계산 출력 단위만 기본 단위로 잘못 쓰인 경우 계산 출력 단위를 피연산자 단위로 맞춘다. 원문 `매`와 허용 출력 `매입`의 동일 수량 표기만 개수 단위 선호 검사에서 허용한다. 수치, 원문 인용, 피연산자, 신뢰도, 출처 충돌 및 계층 검사는 유지한다. 다른 개수 단위 변경은 반려한다.

## 테스트

관련 Java 테스트 36개 통과. 전체 Java 빌드 301개 중 300개 통과, 유료 호출 테스트 1개 제외. Node 13개 통과. v35 운영 데이터셋 2개를 배포 전 백업했다. 처음에는 자동 승인 검토가 명시적 커밋 지시 부재로 거절했으나, 사용자가 v36 커밋·푸시·운영 배포를 명시적으로 승인했다. 배포 및 운영 재검증 결과는 이후 기록한다.

등록 기준값이 원문과 다른 상품은 자동 비교의 `DIFFERENT`만으로 오승인을 확정하지 않는다. v35의 홍삼 상품은 원문에 `50ml×30포×4세트`가 있고 등록 기준은 `1500ml`·`4박스`여서 수량 계층과 기준값을 사람 검토로 확정해야 한다. [v35 변경](v35-허용단위표기_단계.md)과 [기존 한 페이지 요약](운영상품-다양성평가_테스트_한페이지요약.md)을 참조한다.
