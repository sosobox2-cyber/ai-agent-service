# v28 운영 재평가 요구사항

작성일: 2026-10-28 · 단계: 요구사항 · 목적: 배포된 v28의 실제 AI 품질과 승인 차단 효과 확인

사용자의 재테스트 지시에 따라 기존 오류 4상품, 정상 7상품, 충돌 3상품을 같은 원본 입력으로 비교한다. 이후 기존 84상품 밖의 서로 다른 구조 10상품을 선정해 일반화 가능성과 새 오류를 확인한다. 기준은 [고정 평가 기준](오승인-차단-1차_평가기준.md)이다.

정상 대조군은 매핑 값 보존을 검사하고, 오류군은 서버 차단과 AI 자체 수정 여부를 구분한다. 등록값 일치율을 정답률로 보고하지 않는다. 신규 사례의 판정 기준은 호출 전에 로컬 실행 계획에 기록했다.

총 $1 예산은 앞선 실행과 합산한다. 미측정 2회에 대한 $0.16 예약을 유지하며 요청 전 $0.08씩 예약한다. 자동 재전송은 하지 않는다. 기존 검토 메모를 갱신하지 않고 실행 이력만 추가한다. 코드·프롬프트·인프라 배포는 이번 범위에 포함하지 않는다.
