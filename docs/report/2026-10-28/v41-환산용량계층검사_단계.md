# 환산 용량 계층 검사 v41

- 작성일: 2026-10-28 (Asia/Seoul)
- 단계: 요구사항 · 영향분석 · 테스트 · 교차검증
- 범위: 포장식의 낱개 용량이 L로 적히고 AI 출력이 ml인 경우

## 요구사항

`0.05L×30포×4세트`에서 판매 수량이 `4세트`이면 `개당 용량=50ml`는 낱개·포장 계층 혼합이므로 반려한다. AI가 `CONVERT`를 올바르게 지정해도 동일하게 반려한다. 포장당 `1.5L` 또는 동치인 `1500ml`은 근거가 충분할 때만 승인한다.

## 영향분석

실제 AI 최종 승인 검증과 프롬프트 버전, 평가 실행 도구·API 설명에 영향이 있는 높은 위험 변경이다. 물리량 동치 비교를 ml 기준으로 좁게 추가하며 기존 출처·산술 검증은 유지한다.

## 테스트

합성 회귀에서 `0.05L` 원문의 낱개 용량을 `50ml`로 환산해 제안해도 `QUANTITY_LEVEL_MISMATCH`로 반려됨을 확인했다. 관련 Java 테스트 35개 통과. 전체 Java 회귀 313개 실행 중 실패 0개, 기존 조건부 건너뜀 1개이며 Maven package 성공. Node 화면·평가 도구 13개 통과. Railway 배포 `9b36d81` 성공, `TEST_MODE` 스모크는 v41·`success=false`. 데이터셋 2개를 복원하고 비교 대상 파일 357개에서 변경·추가 0건(`352+5`)을 확인했다. 운영 AI로 원래 목표 상품을 1회 재평가해 `4세트 + 1500ml` 승인, 교정 기준 2행 `EXACT`를 확인했다. 이번 호출 추정 비용 $0.0026124, 누적 원장 **$0.6560264 / $1.50**, 미완료 예약 0건. 평가 후 이력을 별도 백업했다.

## 교차검증

운영 v40 소수 리터 변형은 이미 잘못된 `DIRECT` 연산과 출처 누락으로 반려됐다. 이번 변경은 그 두 검사가 우연히 통과하더라도 낱개·포장 계층 혼합을 막는 독립 방어다. 같은 실패 입력을 다시 호출해 통과 여부를 시험하지 않는다.

운영 AI가 소수 리터 변형을 포장당 용량으로 승인한 결과는 아직 없다. 이번 v41 재평가는 원래 상품 입력의 회귀 확인이며, 소수 리터 변형의 자동 승인 성공을 뜻하지 않는다.
