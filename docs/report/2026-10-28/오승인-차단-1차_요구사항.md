# 오승인 차단 1차 요구사항

작성일: 2026-10-28 · 단계: 요구사항 · 목적: 관측된 오승인 유형 차단과 고정 회귀 비교

[운영 평가 요약](운영상품-다양성평가_테스트_한페이지요약.md)을 근거로 사용자에게 제안한 1차 개선을 수행한다.

- 실제 AI가 물리량 근거를 개수 단위로 표기한 제안, 인원 수 없는 사용 인원, 등록번호 근거의 인증번호를 모델명으로 제안한 경우를 반려한다.
- AI 원문 제안은 aiAssessment에 보존하고 최종 결과는 비운다. TEST_MODE 및 기존 신뢰도·재추론 상한은 유지한다.
- 원문 숫자를 서버에서 재계산하지 않는다. 상품명/구성 충돌과 혼합 중량의 대표값 선택은 FULL 프롬프트로 보강하고 실제 AI 개선 효과는 별도로 검증한다.
- 저장된 제안을 같은 입력으로 다시 판정하고 정상 의류·포장·모델 등 대조군의 승인 유지 여부를 확인한다. 등록 기준의 일치율을 정답률로 사용하지 않는다.
- 이번 단계에서 운영 배포, 검토 데이터 갱신, 추가 유료 호출은 실행하지 않는다. 기존 총 $1 예산은 유지한다.

완료 조건: 최종 승인 경로 회귀, 반려 제안 보존, 정상 대조군 검증, 미검증 범위와 후속 운영 비교 계획 기록.
