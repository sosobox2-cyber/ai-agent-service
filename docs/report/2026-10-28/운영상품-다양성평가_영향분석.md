# 운영상품 다양성 평가 — 영향 분석

- 목적: 운영 AI 경로 평가의 비용·이력 영향과 검증 범위를 확인한다.
- 작성일: 2026-10-28
- 단계: 영향분석
- 범위: `scripts/eval-diverse.cjs`, 관련 Node 테스트, 운영 평가 API.
- 이전 단계: [요구사항](운영상품-다양성평가_요구사항.md)

운영 배포 커밋은 `ed0aaa6`, 로컬 HEAD는 `8bb3851`이며 두 버전의 Java·설정·프롬프트는 동일하다. 환경 변수 이름 조회에서도 모델·단가·출력 한도 재정의는 발견되지 않았다. 실제 응답에서 모델과 `coupang-option-v27`을 다시 확인한다.

실제 경로는 EvaluationController → EvaluationService.run(AI) → PurchaseOptionInferenceService → PurchaseOptionAiService → ResultValidator → 실행 이력 저장이다. 실패한 추론의 예외가 EvaluationService에서 처리되면 응답과 usage가 사라질 수 있어, 비용을 0으로 집계하지 않는다.

위험도는 높음: 실제 상품 원문 외부 전송·과금 및 운영 평가 이력 변경을 수반한다. 실행 전 백업, 순차 호출, 2.5초 간격, 재전송 금지, 요청 전 비용 예약, 디스크 원장과 프로세스 잠금으로 통제한다. 애플리케이션 승인·보안·프롬프트 경로는 수정하지 않는다.

단가는 [OpenAI 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-4.1-mini)를 2026-10-28 확인했다. 입력/캐시 입력/출력 100만 토큰당 USD 0.40/0.10/1.60을 사용한다. 현재 v27과 입력 JSON 최대 8,192 bytes, 고정 프롬프트 및 Schema, 출력 4,096 tokens, 최대 2회 호출 조건에서 입력을 회당 65,536 tokens로 보수적으로 잡으면 요청당 USD 0.065536이다. 예약금 USD 0.08, 누적 실행 한도 USD 0.95로 추가 여유를 둔다. 비용 미상 요청은 예약금 전액을 유지하고 배치를 중단한다. 보고 비용은 공급자 청구서가 아닌 usage와 공식 단가에 따른 추정치다.

검증 대상은 표본 다양성, 미측정 비용, 두 호출 합산, 예산 부족 시 전송 차단, 중단 후 예약 보존, 중복 실행 방지다. Node 대역 테스트는 이 도구의 제어만 검증하며 실제 AI 품질은 운영 실행 결과로 별도 평가한다. 원문·원응답·백업은 Git 제외 `logs/diverse-eval-20261028/`에만 둔다.
