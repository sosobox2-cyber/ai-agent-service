# 수량 출처·계층 검증 요구사항

작성일: 2026-10-28 · 단계: 요구사항 · 목적: 출처 충돌 및 개당 물리량 오합산 차단

사용자가 승인한 구조 개선을 수량·개당 수량·개당 중량·개당 용량에 한정한다. FULL은 원문 사실, 출처별 검토 상태, 최종 매핑의 근거 연결을 추가 제출한다. 같은 본품·계층의 수치 충돌, 실제 입력에 없는 인용, 다른 본품의 개당 물리량 합산·대표값 선택은 자동 승인하지 않는다.

이 변경은 기존의 원문 대조 없는 승인 경계를 명시적으로 확장한다. 원문 인용과 제출 숫자 존재, 단일 사실의 단위 동치, 계산 대상·계층을 확인하되 상품 원문 전체를 서버에서 다시 추출하거나 일반 SUM 산술을 재계산하지 않는다.

LIGHT 의류 계약, 모의 추출 TEST_MODE, 기존 신뢰도 및 재추론 상한, 반려 제안 보존은 유지한다. 과거 이력은 새 필드가 없어도 읽을 수 있어야 한다. 새 실제 AI 요청에는 근거 누락을 허용하지 않는다. 이전 응답을 새 버전의 품질 증거로 재사용하지 않는다.

완료 조건은 정상·충돌·위조 출처·단위 동치·혼합 구성·근거 누락 회귀와 전체 Java 검증이다. 실제 AI 호출과 운영 배포는 이번 구현의 완료 증거에 포함하지 않으며 별도 검증 한계로 기록한다.
