# 포장당 용량 계산 v38

- 작성일: 2026-10-28 (Asia/Seoul)
- 단계: 요구사항 · 영향분석 · 테스트 · 교차검증
- 범위: 단일 본품의 명시적 낱개 용량 × 포장 내 개수 × 판매 포장 수

## 요구사항

`50ml×30포×4세트`에서 판매 수량이 `4세트`이면 세트당 용량은 `1500ml`다. `4세트 + 50ml`는 계층이 달라 반려한다. 근거가 불완전하거나 다른 출처와 충돌하면 검토 대상으로 둔다. 전체 판매 용량 `6000ml`을 개당 용량에 쓰지 않는다.

## 영향분석

실제 AI 파싱 후 정규화, 최종 승인 전 근거 검증, FULL 프롬프트와 JSON Schema, 운영 평가 버전·API 설명에 영향이 있다. 승인 결과가 달라지는 높은 위험 변경이다. TEST_MODE와 다른 물리량·다중 본품은 기존 계약을 따른다.

## 테스트

- 합성 회귀: 명시된 식을 `4세트 + 1500ml`로 보완하고 승인; 계산값 변조, 포장 내 개수 근거 누락, 다른 출처 용량 충돌은 반려.
- Java 전체: 309개 실행, 실패 0, 기존 조건부 건너뜀 1; Maven package 성공.
- Node 화면·평가 도구: 13개 통과.
- 운영 AI 실측 결과는 배포 후 같은 비용 원장에서 별도로 기록한다.

## 교차검증

포장당 용량 계산은 세 숫자가 한 단일 본품 구성식에 명시되고, 물리량·포장 내 개수·판매 포장 수의 원문 사실이 같은 본품으로 연결될 때만 허용한다. 값·단위·인용문·계산식이 다르면 서버가 반려한다. 상품명·정보고시의 다른 물리량이 충돌하면 정규화하지 않는다. 원문 형식이 지원 범위를 벗어나면 자동 승인 범위를 확대하지 않는다.
