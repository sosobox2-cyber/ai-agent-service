# 단일상품 기본 수량 정책 v37

작성일: 2026-10-28 · 범위: 실제 AI 승인과 프롬프트, 수량 근거 · 위험도: 높음

## 요구사항

사용자가 **명시 수량이 없는 단일상품은 수량 1개를 자동 승인**하도록 지정했다. 앞서 확인한 상품 20161757의 `4세트 + 개당 용량 50ml`는 판매 포장과 낱개 포의 기준 계층이 달라 자동 승인하면 안 된다.

## 영향분석과 구현

단품이 정확히 하나이고 원본 옵션명이 `단일상품`·`단품`이며 상품명·정보고시·구성에 명시적 개수·포장 수가 없고 요청에서 `개` 단위를 허용하는 경우에만 서버가 `수량=1개`를 보완한다. 출처는 `optionName1`의 실제 문자열이고 숫자 없는 정책 근거를 `quantityEvidence`에 기록한다. 이 규칙은 AI의 다른 매핑과 전체 certain·confidence를 유지하며, 다른 수량 계열의 근거 누락·출처 모호함·중복 검토는 해제하지 않는다. 모의 모드는 자동 승인하지 않는다.

구성에 `50ml×30포×4세트`처럼 낱개 용량·포장 내 개수·판매 포장 수가 명확히 있고 수량이 바깥 포장 수인 경우, 개당 용량에 안쪽 낱개값 `50ml`를 쓰면 `QUANTITY_LEVEL_MISMATCH`로 반려한다. 서버가 포장당 1500ml를 자동 산출하는 계약은 이번 변경에 포함하지 않았다.

실제 AI 운영 재시험: **수량만 있는 단일상품, 중량+수량, 용량+수량의 무수량 사례 3건 모두 승인**, 등록 기준 옵션 5개가 일치했다. 기존 `4세트 + 개당 용량 50ml` 사례는 `QUANTITY_LEVEL_MISMATCH`로 반려됐다. 출처 충돌 2건과 혼합 구성 1건도 반려됐다. 정상 종이 대조 1건은 승인·3개 옵션 일치, 박스 대조 1건은 출력값 2개가 일치했지만 AI가 무관한 `1정`을 포장 계층 근거로 추가해 `QUANTITY_SOURCE_CONFLICT`로 반려됐다. 반복 호출로 통과율을 높이지 않았다. 원래 단일상품 실패 2건은 정보고시에 실제 `x1`이 있어 이번 무수량 정책 대상이 아니며, 한 건에는 중량 근거 충돌도 있었다. 이번 배포 후 11회 호출을 포함한 누적 예산 원장 집계는 **$0.6123952**(미측정 2건 예약 $0.16 포함), 미완료 예약 0건이다. 평가 후 활성 데이터셋을 별도 백업했다.

## 교차검증과 한계

명시 수량 탐지는 보수적 숫자·개수 단위와 `x`·`+` 표현에 한정된다. 한국어 자유 서술의 모든 수량 의미를 증명하지 않는다. 중량·용량 자체를 1로 만들지 않으며, 명시된 포장 수가 있으면 기존 원문 근거 검사를 사용한다. 포장당 1500ml의 자동 산출은 아직 지원하지 않는다. 동일 출력값이더라도 AI가 무관한 근거를 제시하면 검토 필요로 두는 것이 안전하다. [v36 검증](v36-수량단위동치_단계.md), [한 페이지 요약](운영상품-다양성평가_테스트_한페이지요약.md).
