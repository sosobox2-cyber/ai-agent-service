# 포장 표기·단위 경계 v40

- 작성일: 2026-10-28 (Asia/Seoul)
- 단계: 요구사항 · 영향분석 · 테스트 · 교차검증
- 범위: 단일 본품 포장식의 공백 표기, 소수 리터, 다른 출처의 동치·충돌

## 요구사항

`50 ml × 30 포 × 4 세트`는 포장당 `1500ml`, `0.05L×30포×4세트`는 포장당 `1.5L`로 계산한다. 다른 출처의 `50ml`는 `0.05L`와 동치이며, `60ml`는 충돌이다. 근거 인용은 원문의 공백을 보존하고, 구성식이 불완전하거나 충돌하면 승인하지 않는다.

## 영향분석

실제 AI 승인 전 정규화와 포장 계층 검증, FULL 프롬프트·버전, 평가 실행 허용 버전과 API 설명에 영향이 있어 높은 위험 변경이다. 다른 구매옵션 계산·TEST_MODE는 대상이 아니다.

## 테스트

수정 전 추가한 합성 테스트 2개는 공백·소수 리터에서 실패했다. 수정 후 관련 Java 테스트 35개가 통과했고, 추가한 충돌 반려 단언을 포함한 포장 계산 테스트 6개가 통과했다. 전체 Java 회귀 313개 실행 중 실패 0개, 기존 조건부 건너뜀 1개이며 Maven package 성공. Node 화면·평가 도구 13개 통과.

운영 v40 배포 `ad353fe` 성공. 평가 데이터셋 2개를 복원하고 비교 대상 파일 353개에서 변경·추가 0건(`352+1`)을 확인했다. 원래 평가 이력은 유지하고 보조 데이터셋에서 같은 상품 원문의 변형 3개를 실제 AI로 시험했다. 출처를 `60ml`로 충돌시킨 변형은 `QUANTITY_SOURCE_CONFLICT`로 반려됐다. 공백 표기 변형은 `4세트 + 1500ml`로 승인됐다. `0.05L` 변형은 AI가 `50ml`를 `DIRECT`로 잘못 표시하고 상품명 출처 사실을 빠뜨려 `QUANTITY_OPERATION_MISMATCH`·`QUANTITY_SOURCE_COVERAGE`로 반려됐다. 세 호출의 추정 비용은 합계 $0.009946, 누적 원장은 $0.653414 / $1.50이다. 같은 입력을 통과 목적으로 반복 호출하지 않았다.

## 교차검증

용량의 수치 비교에만 ml 환산을 적용하고 저장한 원문 인용·피연산자 단위는 바꾸지 않는다. `50ml`와 `0.05L`는 동치로 보되, 다른 값이나 본품 연결이 불명확한 경우에는 기존 검증이 반려한다. 계산값 변조·근거 누락·명시적 판매 포장 수와 낱개 용량 혼합은 회귀 테스트에서 검사한다.
