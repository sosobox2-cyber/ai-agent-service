## 예산·보존 검토

- 기존 원장에 24회 예약·완료 이벤트를 추가했다. 새 원장으로 초기화하지 않았고 미완료 예약 0건이다.
- 이번 25호출 모두 동일 모델·v28. 입력 207,229, 캐시 155,392, 출력 11,020토큰. 기존 검증 단가로 추정 $0.053906. 누적 확인 추정 비용 $0.2244144, 기존 미측정 2회의 예약 $0.16을 합쳐 $0.3844144.
- 서비스 원본 요청 해시를 매회 확인했고 요청을 변형하지 않았다. 검토 메모 API는 호출하지 않았다.
- 배포 직후 복원 백업과 완료 백업을 비교했다. 원본·메타데이터·기존 실행·검토 137파일 변경 0, 실행 파일 24개 추가. latest 파일은 새 평가 실행에 따라 갱신되므로 동일성 검사에서 제외했다.
- 도구 변경은 v28 허용과 예산 연속성 테스트뿐이다. Node 테스트 9개 통과, git diff --check 통과. 애플리케이션 변경·커밋·푸시·재배포 없음.

AI 어댑터는 검증 실패 시 certain=false로 정리할 수 있다. 따라서 aiAssessment.certain=false만 보고 모델이 스스로 오류를 인지했다고 보고하지 않았으며, validationErrors와 reason의 검증 사유·AI 설명을 함께 확인했다.
