# 운영상품 AI 테스트 결과 — 한 페이지 요약

> **최신 진행 상태(2026-10-28):** 운영 **v41 배포·평가 이력 복원 완료**. 원래 목표 상품 `50ml×30포×4세트`는 v41에서도 `수량=4세트`, `개당 용량=1500ml`로 승인됐고, 사용자 확인으로 교정한 평가 기준 2행 모두 `EXACT`다. 별도 평가 데이터셋의 변형 시험에서는 숫자·단위 공백 표기가 승인되고, 출처의 상충 용량은 반려됐다. `0.05L` 변형은 AI가 환산을 `DIRECT`로 잘못 표시하고 출처 사실을 누락해 검토 대상으로 남았다. v41은 이 제안이 `CONVERT`로 제출되더라도 `4세트 + 낱개 용량 50ml` 계층 혼합을 반려하도록 보강했다. 운영 AI에서 소수 리터 변형의 자동 승인 성공은 아직 확인되지 않았다. 원본 등록 수량 `4박스`는 보존하고 평가 비교값만 `4세트`로 교정했다. 누적 비용 원장 집계는 **$0.6560264 / $1.50**(미측정 2건 예약 $0.16 포함)이다. [v41 상세 검증](v41-환산용량계층검사_단계.md) · [v40 변형 시험](v40-포장표기단위경계_단계.md). 아래 표는 최초 평가 당시 기록이다.

**작성일:** 2026-10-28 · **단계:** 테스트 요약 · **대상:** Railway 운영서버 · **목적:** 구매옵션별 오류와 개선 우선순위 확인

**우선 개선할 부분은 단위·속성의 의미 검증과 원문 충돌 처리다.** 프롬프트 예시를 늘리는 것과 함께 구매옵션별 의미·허용 근거를 명확히 해야 한다. 등록 기준값에도 오류가 있어 평가 기준 정리가 병행되어야 한다.

## 실행 결과

| 항목 | 결과 |
|---|---|
| 테스트 규모 | **84상품·95회 요청** — 1차 72상품, 보강 12상품, 대조·재실행 11회 |
| 다양성 | 1차 표본에 구매옵션 **68종**, 옵션 조합 62종, 상품군 12개 포함 |
| 모델 / 프롬프트 | gpt-4.1-mini-2025-04-14 / coupang-option-v27 |
| 비용 | 확인된 추정 비용 **$0.171** · 미측정 2건의 여유예산 포함 **$0.331**로 집계; 예산 $1 이내 |
| 1차 서버 승인 | **36/72상품(50.0%)** |
| 1차 기준 행 일치 | **74/238행(31.1%)** — 등록 기준과의 비교이며 정답률이 아님 |
| 응답·경계 | 평균 처리 2.81초 · 40단품 요청 2건 모두 출력 한도 초과 |

비용은 usage와 공식 단가로 계산한 추정치다. 출력 한도 오류 2건은 usage가 없어 각각 $0.08을 보수적으로 반영했다. 표본은 오류 발견을 위한 다양성 중심 선정이며, 68종 중 시험용 데이터만 있는 옵션도 있어 전체 운영 정확도로 일반화할 수 없다.

## 핵심 발견과 개선 순서

| 순서 | 확인된 문제 | 개선 방향 |
|---|---|---|
| **1. 오승인 차단** | `70ml → 70개입`, 사용 인원=`PLUS`, 인증번호를 모델명으로 승인. 동일 입력 재실행에서도 반복 | 기본단위 적용을 같은 의미 차원으로 제한하고 옵션별 값 유형·허용 출처 정의 |
| **2. 구성·충돌 판정** | 상품명과 기술서의 16/17매·3/4팩 충돌을 승인하고, 혼합 중량에서 대표값 선택 | 본품·판매 포장·내용물 계층을 구분하고 충돌·대표값 임의 선택은 검토로 전환 |
| **3. 근거·응답 계약 개선** | 상품명의 명시 사양 누락, 빈 매핑, `2L`와 계산 출력단위 `ml` 불일치 | 출처 탐색 순서 정리, 값·단위 중복 생성 축소, 생략·스칼라·규격 문자열 계약 분리 |
| **4. 처리 구조 보강** | 40단품 출력 잘림 및 실패 응답의 usage 소실 | 예상 출력량에 따른 요청 분할, 통합 후 단품·조합 검사, 실패 시에도 사용량 보존 |
| **병행. 평가 기준 정리** | 색상·사이즈 기준 열 뒤바뀜, 근거 없는 등록값, 동의어 차이 | 부적합 기준 분리, 사람 검토와 자동 비교 구분, 교정 근거 기록 |

1차 승인 36상품 중 **최소 11상품에서 의미·근거·계약 위반을 확인**했다. 이는 에이전트의 원문 대조 결과이며 사람의 최종 정답 확정은 아니다. 반면 명확한 의류 색상·사이즈는 5단품 10행과 16단품 32행이 모두 일치했다. `없음 → 단일상품` 표시 변경만으로 승인 여부가 달라졌지만, 매핑이 그대로인 사례도 있어 일괄 치환의 개선 효과는 입증되지 않았다.

## 반영 상태와 다음 단계

운영 평가 이력에 **95회 실행 결과 저장 완료**. 실행 전후 원본·기존 검토 28개 파일은 동일했다. 평가 도구 테스트 8개가 통과했으며, 운영 프롬프트·애플리케이션은 이번 평가에서 변경하지 않았다. **검토 메모 30상품·57행은 초안만 준비**했으며, 자동 승인 검토가 영구 운영 데이터 추가에 별도 승인이 필요하다고 판단해 저장하지 않았다.

다음 작업은 **검토 기준 확정 → 오승인 차단 규칙 설계 → 고정 평가셋으로 변경 전후 비교** 순서가 적절하다. 개선율은 이 재검증 이후 산출한다.
