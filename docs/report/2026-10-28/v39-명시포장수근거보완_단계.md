# 명시 포장 수 근거 보완 v39

## 요구사항

v38 운영 목표 사례에서 AI는 세트당 용량 `1500ml`을 정확히 계산했지만, 명시적 `4세트`의 `PACK_COUNT` 피연산자를 빈 목록으로 제출해 자동 승인이 보류됐다. 같은 구성 원문의 `4세트`와 본품 `COUNT/TOTAL` 사실이 일치할 때만 피연산자를 보완한다.

## 영향분석

실제 AI 제안 정규화와 최종 승인 결과에 영향이 있어 높은 위험 변경이다. 원문·본품·계산식이 일치하지 않는 빈 피연산자는 계속 반려한다. `PACK_CAPACITY` 값과 다른 구매옵션의 검증 경로는 그대로 둔다.

## 교차검증

수량 값, 포장식, 본품의 `COUNT/TOTAL` 사실이 일치하는지 확인한 뒤 빈 피연산자를 고친다. AI가 제시한 용량 계산 자체는 별도 산술·출처 검증을 다시 거친다.

목표 사례의 원본 등록 기준은 `개당 용량=1500ml`, `수량=4박스`다. v39의 용량 `1500ml`은 이미 `EXACT`이며 남은 `DIFFERENT`는 수량 `4박스` 대 `4세트`다. 상품명은 `3+1박스`, 구성은 `4세트`라고 표현한다. 두 단위의 동치 여부가 확정되기 전에는 수량 기준을 임의로 바꾸지 않는다. 앞선 한 페이지 요약의 “용량 50ml 기준 불일치” 서술은 원본 기준값을 잘못 짚은 것이므로 정정했다.

로컬 회귀에서 `50ml x 30포 x 4세트`와 `50ml * 30포 * 4세트`는 포장당 용량 계산을 통과했고, 별도 출처의 `40ml` 충돌은 정규화되지 않았다. 관련 Java 테스트 4개가 통과했다.

## 평가 기준 교정과 재검증

사용자가 이 상품의 `1세트=1박스`를 확인했다. 변경 전 평가 데이터셋을 백업한 다음 수량 152행에 `REFERENCE_ISSUE`, 확정 비교값 `4세트`, 동치 확인 메모를 기록했다. 원본 등록값 `4박스`와 용량 151행의 기준 `1500ml`은 보존했다. 같은 상품을 운영 AI로 1회 재평가한 결과 `수량=4세트`, `개당 용량=1500ml`이 서버 승인됐고 두 행 모두 `EXACT`였다. 이번 호출 추정 비용은 $0.0021776, 누적 원장은 **$0.643468 / $1.50**, 미완료 예약 0건이다. 교정 후 평가 데이터셋도 별도로 백업했다. 이 비교 개선은 기준 교정에 따른 것으로 모델 성능 향상으로 계산하지 않는다.
