# 오승인 차단 1차 고정 평가 기준

작성일: 2026-10-28 · 목적: 승인 차단과 추출 품질을 분리하여 비교 · 상태: 에이전트 검토 기준, 사람의 최종 정답 확정 아님

## 이번 변경의 고정 회귀

| 유형 | 사례 | 기대 판정과 근거 |
|---|---|---|
| 차원 오류 | c03774, c04671 | 물리량을 개당 수량으로 표시한 기존 제안은 반려. 수정 후 수량을 몇 개로 바꿀지는 별도 근거 검토 |
| 인원 유형 | c08630 | PLUS는 인원 수가 아니므로 반려. 등록된 가격 숫자도 정답으로 쓰지 않음 |
| 모델 출처 | c01154 | 등록번호 근거의 인증번호를 모델명으로 승인하지 않음 |
| 정상 의류 | c01513, c01900 | 서로 다른 단품의 색상·사이즈 매핑 및 승인 유지 |
| 정상 포장 | c00803, c00005 | 길이/내용물 수/판매 포장 수를 분리한 기존 매핑 유지 |
| 본품/사은품 | c05158 | 본품 중량에 다른 구성품을 섞지 않은 기존 매핑 유지 |
| 다른 속성 | c05519, c07325 | 골프 옵션, 화면 크기·모델 정상 매핑 유지 |

합성 입력의 고정 단위 테스트는 `AiValueContractTest`, 기존 운영 제안의 오프라인 재판정은 `StoredProposalReplayTest`에 둔다. 원본 상품 본문은 저장소에 새로 복사하지 않고 무시된 로컬 이력에서 읽는다. 후자는 기존 이력이 있어야 실행할 수 있다.

## 실제 AI 재비교 때 추가할 기준

| 유형 | 사례 | 기준 |
|---|---|---|
| 출처 충돌 | c00611, c00168 | 같은 본품·계층의 불일치 해소 불가 시 certain=false. 단순 누락 처리만 하고 승인하면 실패 |
| 혼합 중량 | c10125 | 대표 중량 임의 선택을 금지. 총중량 기준값을 개당 중량 정답으로 쓰지 않음 |
| 근거 누락 | c05694, c09779 | 명시된 등급·사양 추출 여부를 비교. 승인 증가만으로 개선이라고 판단하지 않음 |
| 응답 계약 | c01248 | 최종 값의 단위와 calculation.outputUnit 일치. 값만 바꿔 반려를 피하는지 함께 확인 |
| 기준 데이터 오류 | c00134, c09493, c06047 | 뒤바뀐 열·차원 오류·표기 혼합 기준은 정답률 분모에서 제외하고 별도 검토 |
| 미사용 사례 | 기존 84상품 밖에서 선택 | 단위 차원·포장·인원·모델의 서로 다른 문장/단위, 정상과 오류를 균형 있게 구성 |

배포 승인 후 위 오류 4상품 + 정상 7상품 + 충돌 3상품을 먼저 비교하고, 남은 예산을 확인한 뒤 미사용 사례로 확장한다. 각 호출 전에 기존 비용·미측정 예약액을 이어서 합산한다. 호출별 여유 비용은 수정된 프롬프트 길이와 토큰 상한에 맞게 다시 확인해야 한다. 총 $1을 새 배치의 예산으로 초기화하지 않는다.

보고 지표는 오류 제안 차단 수, 정상 사례 유지 수, 필요한 속성 추출 수, 미검토/기준 부적합 수, 비용이다. 같은 상품 반복 요청은 독립 상품처럼 세지 않는다. 현재 4상품 차단을 전체 운영 정확도나 프롬프트 개선율로 일반화하지 않는다.
