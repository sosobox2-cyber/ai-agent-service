# AI Agent Service 소개와 사용 안내

이 문서는 상품 운영 담당자, 기획자 등 개발 지식 없이 이 프로젝트를 이해하고 시험해 보고 싶은 분들을 위한 안내입니다.

## 1. 어떤 일을 하는 서비스인가요?

SK스토아 상품의 단품 옵션명을 읽고, 쿠팡에서 사용하는 구매옵션 항목에 맞춰 값을 나누어 주는 서비스입니다.

예를 들어 SK스토아에 `블랙/90`이라고 적힌 옵션이 있다면, 쿠팡에 필요한 항목에 맞춰 다음처럼 정리합니다.

| 원본 단품 옵션명 | 쿠팡 구매옵션명 | 추출한 값 |
|---|---|---|
| 블랙/90 | 패션의류/잡화 사이즈 | 90 |
| 블랙/90 | 색상 | 블랙 |

사람이 옵션명을 하나씩 읽고 색상과 사이즈를 나누는 작업을 돕는 것이 목적입니다. 현재는 결과를 확인하는 단계까지 제공하며, 쿠팡에 상품을 등록하거나 기존 상품을 수정하지는 않습니다.

## 2. 왜 필요한가요?

판매처마다 상품 옵션을 표현하는 방식이 다릅니다. 한 곳에는 색상과 사이즈가 한 문장에 들어 있고, 다른 곳에서는 각각 별도 항목으로 입력해야 할 수 있습니다.

이 서비스는 원본 표현을 읽어 항목별 값을 제안하고, 빠진 항목이나 중복 조합을 검사합니다. 이를 통해 담당자가 반복해서 값을 나누는 작업과 결과를 검토하는 작업을 지원합니다. 실제 업무 시간 절감이나 정확도는 아직 측정하지 않았습니다.

## 3. 어떻게 판단하나요?

처리는 다음 순서로 진행됩니다.

1. **상품 정보를 받습니다.** 상품명, 브랜드, 카테고리, 단품 옵션명과 필요한 구매옵션명을 입력받습니다.
2. **AI가 원본 옵션명의 의미를 읽습니다.** 상품정보고시가 있으면 색상·치수 등의 설명도 참고합니다.
3. **프로그램이 결과를 검사합니다.** 원본에 있는 값을 사용했는지, 필수 항목이 빠지지 않았는지, 서로 다른 단품이 같은 조합으로 정리되지 않았는지 확인합니다.
4. **결과와 판단 사유를 보여줍니다.** 확인을 통과한 결과는 적용 후보로, 모호하거나 조건에 맞지 않는 결과는 검토가 필요한 것으로 표시합니다.

### 상품정보고시는 어떤 역할을 하나요?

상품정보고시는 옵션명의 의미를 이해하는 참고 자료입니다. 항목명과 값을 긴 텍스트로 붙여 넣으면 됩니다.

```text
색상: 블랙
치수: S(90) / M(95) / L(100) / XL(105)
제조국: 베트남
```

원본 옵션명이 `블랙/90`이면 사이즈 값은 `90`입니다. 정보고시에 `S(90)`가 적혀 있어도 원본에 없는 `S`로 바꾸지 않습니다. 원본 옵션명에 빠진 값을 상품정보고시만 보고 채우지도 않습니다.

## 4. 사용 전에 무엇을 준비해야 하나요?

담당 개발자에게 서비스를 실행해 달라고 요청한 뒤 테스트 페이지를 엽니다. 같은 PC에서 실행했다면 기본 주소는 [http://127.0.0.1:8081/](http://127.0.0.1:8081/)입니다. 다른 PC나 배포된 서버를 사용한다면 담당자가 안내한 주소로 접속하세요.

| 준비할 내용 | 입력 방법 |
|---|---|
| 상품 정보 | 상품 코드, 상품명, 브랜드와 SK스토아 카테고리 |
| 쿠팡 카테고리 | 대상 카테고리의 키와 이름 |
| 허용 구매옵션명 | 해당 카테고리에서 사용할 수 있는 항목명 |
| 필수 구매옵션명 | 각 단품에 꼭 있어야 하는 항목명. 허용 항목 중에서 선택 |
| 단품 정보 | 단품을 구별하는 ID와 원본 옵션명 |
| SK스토아 상품정보고시 | 소재·색상·치수 등의 항목명과 값. 선택 입력 |

상품·카테고리·구매옵션명은 사용자가 준비해서 입력해야 합니다. 현재 서비스가 판매처에서 자동으로 가져오지는 않습니다.

허용 구매옵션명은 2~20개, 단품은 1~200개까지 입력할 수 있습니다. 상품정보고시는 최대 20,000자입니다. 단품 ID는 서로 달라야 하며, 원본 옵션명은 미리 나누거나 바꾸지 않고 그대로 입력합니다.

## 5. 테스트 페이지 사용 방법

### 먼저 기본 예제로 확인하기

1. 테스트 페이지에서 **아이그너 니트탑 예제** 버튼을 누릅니다. 페이지를 처음 열 때도 이 예제가 기본으로 채워집니다.
2. 상품 코드가 `68535109`인지 확인합니다.
3. 단품이 `블랙/90`, `블랙/95`, `블랙/100`, `블랙/105` 네 개인지 확인합니다.
4. **테스트 모드**를 켠 상태로 **매핑 결과 확인** 버튼을 누릅니다.
5. 결과 표에서 색상은 `블랙`, 사이즈는 각각 `90`, `95`, `100`, `105`로 나뉘는지 확인합니다.

예제에는 주어진 SK스토아 상품정보고시 9개 항목도 포함되어 있습니다. 단품 ID `1`~`4`는 예제용 번호입니다.

### 내 상품으로 확인하기

1. **상품 정보** 영역에 상품 코드, 상품명, 브랜드와 두 판매처의 카테고리를 입력합니다.
2. **SK스토아 상품정보고시** 입력란에 고시 내용을 붙여 넣습니다. 줄바꿈을 사용해도 됩니다.
3. **쿠팡 구매옵션명** 영역에 허용 항목과 필수 항목을 입력합니다. 항목명은 쉼표나 줄바꿈으로 구분합니다.
4. **원본 단품 옵션** 영역에 단품별 ID와 옵션명을 입력합니다. 필요하면 **+ 단품 추가**로 행을 늘립니다.
5. 원하는 처리 모드를 선택하고 **매핑 결과 확인**을 누릅니다.
6. 결과 표와 판단 사유, **확인할 항목**을 함께 읽습니다.

### 테스트 모드와 실제 AI의 차이

| 구분 | 테스트 모드 켜기 | 테스트 모드 끄기 |
|---|---|---|
| 판단 방식 | 미리 정한 기본 패턴으로 모의 추출 | 실제 AI가 상품과 옵션 정보를 읽고 판단 |
| 확인할 수 있는 것 | 화면과 결과 표시, 기본 색상·숫자 사이즈·핏 추출 | 상품정보고시를 참고한 판단과 다양한 표현의 해석 |
| 사전 준비 | AI 인증 키 없이 사용 가능 | 담당자가 AI 인증 키와 통신 환경을 설정해야 함 |
| 자동 적용 후보 | 항상 아니요 | 검사와 신뢰도 기준을 통과하면 예 |

테스트 모드는 실제 AI의 성능을 확인하는 기능이 아닙니다. 정보고시를 입력해도 그 내용을 해석하지 않으므로, 정보고시를 활용한 판단은 테스트 모드를 끄고 확인하세요.

## 6. 결과는 어떻게 읽으면 되나요?

| 화면 표시 | 의미와 다음 행동 |
|---|---|
| 테스트 결과 · 모의 | 기본 규칙으로 만든 시험 결과입니다. 입력과 표시가 맞는지 확인합니다. |
| 매핑 성공 | 실제 AI 결과가 현재 검사 기준을 통과했습니다. 추출된 값과 판단 사유를 확인합니다. |
| 검토 필요 | 누락·중복·모호함 등의 이유로 적용 후보가 되지 못했습니다. 확인할 항목을 읽고 원본 데이터를 점검합니다. |
| 요청 오류 / 연결 오류 | 입력이나 AI 통신에 문제가 생겼습니다. 표시된 사유와 오류 코드를 담당자에게 전달합니다. |

**자동 적용 후보 ‘예’는 상품에 이미 적용됐다는 뜻이 아닙니다.** 다음 업무 단계에서 사용할 수 있는 후보라는 뜻이며, 이 서비스는 결과를 보여줄 뿐 상품을 직접 변경하지 않습니다.

**신뢰도는 정답률이 아닙니다.** AI가 제시한 확신 정도입니다. 현재는 전체 판단과 개별 값의 신뢰도가 모두 95% 이상이고, 프로그램 검사도 통과해야 적용 후보가 됩니다. 높은 수치만 보지 말고 실제 색상·사이즈가 맞는지도 확인하세요.

검증에 실패하거나 검토가 필요한 경우 결과 표가 비어 있을 수 있습니다. 이때는 판단 사유와 **확인할 항목**을 먼저 읽습니다.

## 7. 현재 할 수 있는 일과 범위

| 항목 | 현재 제공 범위 |
|---|---|
| 단품 옵션 정리 | 원본 옵션명에서 지정한 쿠팡 구매옵션별 값 추출 |
| 정보고시 활용 | 옵션명을 이해하는 참고 자료로 활용 |
| 결과 점검 | 원본 값 존재 여부, 필수 항목 누락, 조합 중복 등 검사 |
| 판매처 연동 | 상품 조회·등록·수정 기능은 아직 없음 |
| 정보고시 변환 | 쿠팡 상품정보고시를 별도로 생성하는 기능은 아직 없음 |
| 결과 보관 | 결과를 저장하거나 이전 결과를 조회하는 기능은 아직 없음 |

상품 정보를 보내면 항상 모든 값을 알아낼 수 있는 것은 아닙니다. 예를 들어 `A형`만 적혀 있고 색상·사이즈를 알 수 없으면 검토가 필요합니다. 또한 단품 입력 상한인 200개가 모든 상품에서 AI 처리 완료를 보장하는 것은 아닙니다.

실제 AI 모드에서는 입력한 상품 정보와 정보고시가 외부 AI 서비스인 OpenAI로 전송됩니다. 업무에서 사용할 데이터의 공유 범위를 확인한 뒤 입력하세요.

## 8. 잘 안 될 때 확인할 사항

| 증상 | 확인 방법 |
|---|---|
| 페이지가 열리지 않음 | 서비스가 실행 중인지, 접속 주소가 맞는지 담당자에게 확인합니다. |
| 예전 화면이나 예제가 보임 | Ctrl+F5로 새로고침합니다. 그대로라면 실행 중인 서비스가 최신 버전인지 확인을 요청합니다. |
| 필수 항목이 빠졌다고 나옴 | 원본 옵션명에 실제 값이 있는지, 필수 구매옵션명을 정확하게 입력했는지 확인합니다. |
| 서로 다른 단품이 같은 조합이라고 나옴 | 단품을 중복 입력했는지 확인합니다. 실제로 다른 단품이라면 두 단품을 구별할 정보가 부족한지 담당자가 확인해야 합니다. |
| 실제 AI만 연결되지 않음 | 표시된 오류 코드와 발생 시간을 전달합니다. 담당자가 인증 키, 호출 한도, 회사 VPN·인증서 설정 등을 확인합니다. |

기술 담당자를 위한 처리 흐름과 상세 사양은 [project-flow.md](project-flow.md), 실행 방법은 [README.md](../README.md)를 참고하세요.
