# 쿠팡 구매옵션 AI 분석 서비스 사용설명서

이 문서는 상품 운영 담당자와 기획자 등 **개발 지식이 없는 사용자도 서비스를 쉽게 이해하고 직접 테스트할 수 있도록**<br>작성된 안내서입니다.

먼저 사용 방법을 확인하여 서비스의 주요 기능을 테스트해 보시고, 개발과 관련된 세부 내용은 별도의 기술 문서를 참고해 주세요.

---

## 1. 어떤 일을 하는 서비스인가요?

SK스토아 상품의 **단품 옵션명을 분석하여 쿠팡에서 사용하는 구매옵션 항목에 맞게 값을 구분해 주는 서비스**입니다.

예를 들어 SK스토아의 단품 옵션명이 `블랙/90`인 경우 다음과 같이 분석합니다.

| 원본 단품 옵션명 | 쿠팡 구매옵션명 | 추출한 값 |
| :--- | :--- | :--- |
| 블랙/90 | 패션의류/잡화 사이즈 | 90 |
| 블랙/90 | 색상 | 블랙 |

즉, 사람이 단품 옵션명을 하나씩 확인하면서 **색상, 사이즈, 수량, 용량 등의 값을 직접 구분하는 작업을 줄여주는 역할**을 합니다.

현재는 **옵션 분석 및 결과 확인 기능만 제공**합니다.

분석 결과를 이용하여 쿠팡에 상품을 직접 등록하거나 기존 쿠팡 상품을 수정하지는 않습니다.

---

## 2. 왜 필요한가요?

판매처마다 상품 옵션을 표현하는 방식이 다릅니다.

예를 들어 SK스토아에서는 `블랙/90`처럼 색상과 사이즈가 하나의 옵션명에 함께 표시될 수 있지만, 쿠팡에서는 이를 다음과 같이 각각의 구매옵션으로 구분해야 할 수 있습니다.

- 색상 → `블랙`
- 패션의류/잡화 사이즈 → `90`

상품과 단품이 많아질수록 사람이 이러한 값을 하나씩 확인하고 구분하는 작업에는 많은 반복 작업이 필요합니다.

이 서비스는 원본 단품 옵션명을 분석하여 **쿠팡 구매옵션에 맞는 값을 자동으로 제안**합니다.

또한 단품이 빠졌거나 동일한 옵션 조합이 중복되는 등의 문제를 함께 확인하여 결과 검토를 도와줍니다.

현재는 실제 업무 시간 절감 효과와 전체 상품에 대한 AI 분석 정확도를 측정하는 단계이므로 **분석 결과는 최종 적용 전에 확인하는 것을 권장합니다.**

---

## 3. 어떤 정보를 이용해서 판단하나요?

서비스는 다음 정보를 이용하여 상품의 구매옵션을 판단합니다.

### 기본적으로 사용하는 정보

- 상품명
- 내부 카테고리
- 원본 단품 옵션명
- 쿠팡 구매옵션명
- SK스토아 상품정보고시

필요한 경우 **상품 기술서·구성 정보**도 추가로 입력할 수 있습니다.

서비스는 입력된 정보를 바탕으로 AI가 각 단품을 분석하고, 이후 프로그램이 결과에 문제가 없는지 다시 확인합니다.

최종적으로 화면에서 다음 내용을 확인할 수 있습니다.

- 단품별 구매옵션 분석 결과
- AI가 판단한 내용
- 프로그램의 검증 결과
- 검토가 필요한 이유

---

## 4. 어떻게 분석하나요?

상품 정보를 입력하고 분석을 요청하면 다음 순서로 처리됩니다.

### ① 상품 정보를 확인합니다

상품명, 카테고리, 단품 옵션명, 상품정보고시 등 입력된 상품 정보를 확인합니다.

### ② AI가 옵션을 분석합니다

AI가 각 단품의 옵션명을 읽고 쿠팡에서 사용하는 구매옵션에 맞는 값을 제안합니다.

예를 들어

`블랙/90`

이라는 옵션을 보고

- 색상 → `블랙`
- 패션의류/잡화 사이즈 → `90`

과 같이 판단합니다.

### ③ 프로그램이 결과를 검사합니다

AI가 결과를 만들었다고 바로 사용하는 것은 아닙니다.

프로그램이 다음과 같은 문제가 없는지 추가로 확인합니다.

- 단품이 빠지지 않았는지
- 허용되지 않은 구매옵션이 사용되지 않았는지
- 동일한 옵션 조합이 중복되지 않았는지
- 필요한 값이나 단위가 잘못 입력되지 않았는지
- 최종 옵션 조합에 문제가 없는지

### ④ 최종 결과를 보여줍니다

검사가 끝나면 **최종 단품 결과**와 함께 AI와 프로그램이 어떤 판단을 했는지 화면에 표시합니다.

---

## 5. 결과에 문제가 있으면 자동으로 다시 분석합니다

일반적인 색상·사이즈 상품은 먼저 간단한 방식으로 분석합니다.

첫 번째 분석에서 일부 단품이 빠지거나 값을 명확하게 판단하지 못하는 등의 문제가 발견되면 **사용자가 별도로 요청하지 않아도 더 자세한 방식으로 한 번 더 분석합니다.**

따라서 사용자가 별도의 버튼을 누를 필요는 없습니다.

| 상황 | 처리 방법 |
| :--- | :--- |
| 첫 번째 분석 결과가 정상인 경우 | 해당 결과를 바로 보여줍니다. |
| 첫 번째 분석 결과에 문제가 있는 경우 | 더 자세한 방식으로 한 번 더 분석합니다. |
| 처음부터 자세한 분석이 필요한 상품 | 처음부터 상세하게 분석합니다. |
| 연결 문제나 응답 지연 등의 오류 | 분석을 중단하고 오류를 안내합니다. |

두 번째 분석 후에도 결과를 사용하기 어렵다면 **검토 필요**로 표시됩니다.

이 경우 화면의 **판단 사유**와 **확인할 항목**을 확인해 주세요.

원인을 알기 어렵다면 **상품 ID와 실행 시각, 화면에 표시된 사유**를 담당자에게 전달해 주세요.

> **참고**
>
> 화면의 신뢰도가 낮다는 이유만으로 다시 분석하는 것은 아닙니다. 단품 누락이나 잘못된 옵션 매핑 등 결과 자체에 문제가 있는지를 함께 확인하여 추가 분석 여부를 판단합니다.

---

## 6. 상품정보고시는 왜 입력하나요?

상품정보고시는 AI가 **옵션명의 의미와 상품의 특성을 이해하기 위한 참고 자료**로 사용합니다.

SK스토아 상품정보고시의 항목명과 값을 그대로 붙여 넣어 사용할 수 있습니다.

예를 들어 다음과 같이 입력할 수 있습니다.

```text
색상: 블랙
치수: S(90) / M(95) / L(100) / XL(105)
제조국: 베트남
```

다만 상품정보고시는 **원본 옵션명을 임의로 변경하기 위한 정보가 아닙니다.**

예를 들어 원본 옵션명이

`블랙/90`

이라면 사이즈는 `90`으로 판단합니다.

상품정보고시에 `S(90)`이라고 적혀 있더라도 원본 옵션명에 없는 `S`를 임의로 추가하여 `S`로 변경하지 않습니다.

일반적인 색상·사이즈·핏 역시 원본 옵션명에 없는 값을 상품정보고시만 보고 임의로 추가하지 않습니다.

---

## 7. 상품 기술서·구성은 언제 사용하나요?

상품정보고시만으로 상품의 수량이나 구성을 판단하기 어려운 경우 **상품 기술서·구성**을 추가로 입력할 수 있습니다.

이 항목은 선택 사항입니다.

화면에서 **상품 기술서 · 구성 (선택)**을 선택하면 입력란을 열 수 있습니다.

예를 들어 다음과 같은 상품에서 활용할 수 있습니다.

| 상품 구성 예 | AI가 확인할 내용 |
| :--- | :--- |
| 본품 선크림 50ml 7개 + 사은품 파우치 1개 | 본품은 7개이며 개당 용량은 50ml인지 확인 |
| 칫솔 10개 세트 (5색상 각 2개) | 한 세트 안에 칫솔이 총 10개인지 확인 |

가능하면 기술서의 상품 구성을 **원문 그대로 입력**해 주세요.

특히 다음 내용을 명확하게 구분하는 것이 좋습니다.

- 본품
- 사은품·증정품
- 판매 세트 수
- 한 세트 안에 포함된 상품 수
- 개당 용량이나 중량

무료체험분, 사은품, 증정품은 본품 수량을 판단할 때 제외할 수 있습니다.

상품명, 상품정보고시, 기술서의 내용이 서로 다르면 AI가 **검토 필요**로 판단할 수 있습니다.

---

## 8. 옵션명이 `단일상품` 또는 `단품`인 경우

단품이 하나뿐이고 옵션명이 `단일상품` 또는 `단품`처럼 구체적인 정보를 포함하지 않는 경우가 있습니다.

이 경우에는 옵션명만으로 수량이나 규격을 알 수 없기 때문에 AI가 다음 정보를 함께 참고합니다.

- 상품명
- 상품정보고시
- 상품 기술서·구성

예를 들어 상품 정보에 다음 내용이 있다고 가정합니다.

| 구매옵션명 | 판단 결과 | 판단 근거 |
| :--- | :--- | :--- |
| 수량 | 9개 | 상품명에 본품 9박스로 표시 |
| 개당 수량 | 50개입 | 상품정보고시에 총 50패치로 표시 |

구성이나 수량을 명확하게 판단할 수 없는 경우에는 값을 임의로 만들지 않고 **검토 필요**로 표시될 수 있습니다.

## 9. 테스트 페이지 사용 방법

실제로 서비스를 테스트할 때는 다음 순서로 진행하면 됩니다.

### ① 상품 정보를 입력합니다

**예제 불러오기**를 이용하거나 직접 상품 정보를 입력합니다.

내부 카테고리는 필수 입력입니다.

### ② 쿠팡 구매옵션명을 입력합니다

해당 상품에서 사용할 수 있는 쿠팡 구매옵션명을 입력합니다.

예:

```text
패션의류/잡화 사이즈
색상
```

여러 개가 필요한 경우 **+ 구매옵션 추가**를 이용합니다.

### ③ 원본 단품을 입력합니다

각 단품의 ID와 실제 옵션명을 입력합니다.

예:

```text
단품 ID : 001
옵션명  : 블랙/90
```

단품 ID는 서로 중복되지 않도록 입력해 주세요.

### ④ SK스토아 상품정보고시를 입력합니다

상품정보고시는 필수 입력입니다.

필요한 경우 **상품 기술서·구성**과 구매옵션별 단위도 추가로 설정합니다.

### ⑤ 분석 방식을 선택합니다

**테스트 모드** 또는 **실제 AI 추론**을 선택한 후 요청을 보냅니다.

### ⑥ 결과를 확인합니다

결과가 나오면 가장 먼저 **최종 단품 결과**를 확인하세요.

필요한 경우 AI·서버 판단 및 검증 내용을 펼쳐 상세한 판단 이유를 확인할 수 있습니다.

## 10. 테스트 모드와 실제 AI 추론의 차이

두 가지 방법으로 서비스를 테스트할 수 있습니다.

| 구분 | 테스트 모드 | 실제 AI 추론 |
| :--- | :--- | :--- |
| 실제 AI 사용 | 사용하지 않음 | 사용 |
| API 키 | 필요 없음 | 서버 설정 필요 |
| 판단 방식 | 일부 정해진 패턴을 이용한 테스트 | AI가 실제 상품 정보를 분석 |
| 결과 | 테스트용 결과 | 실제 AI 분석 결과 |
| AI 사용 비용 | 없음 | 발생 |

### 테스트 모드

화면이나 요청 방식이 정상적으로 동작하는지 간단하게 확인하기 위한 기능입니다.

**실제 AI의 정확도를 평가하는 기능은 아닙니다.**

지원하지 않는 상품 표현은 결과가 없거나 검증에 실패할 수 있습니다.

### 실제 AI 추론

입력한 상품명, 옵션명, 상품정보고시, 기술서 등을 실제 AI가 분석합니다.

실제 AI API를 사용하므로 사용량에 따른 비용이 발생합니다.

## 11. 구매옵션의 단위는 어떻게 설정하나요?

수량, 용량, 중량처럼 단위가 필요한 구매옵션은 기본 단위와 사용할 수 있는 단위를 지정할 수 있습니다.

예:

| 구매옵션명 | 기본단위 | 사용할 수 있는 단위 |
| :--- | :--- | :--- |
| 색상 | - | - |
| 패션의류/잡화 사이즈 | - | - |
| 수량 | 개 | 개, 박스, 세트 |
| 개당 용량 | ml | ml, L |

색상이나 일반적인 사이즈처럼 별도의 단위가 필요하지 않은 항목은 옵션명만 입력하면 됩니다.

단위를 설정하려면 **기본단위와 사용할 수 있는 단위를 모두 입력**해 주세요.

예를 들어 수량의 기본단위를 `개`로 설정했다면 AI가 원문의 단위를 명확하게 사용할 수 없는 경우 `개`를 사용할 수 있습니다.

단, 단위가 바뀐다고 해서 수량 자체를 임의로 계산하는 것은 아닙니다.

예를 들어 `1박스 = 10개`라는 정보가 없다면 `6박스`를 임의로 `60개`로 계산하지 않습니다.

숫자 자체를 알 수 없는 경우에도 임의의 숫자를 만들어내지 않습니다.

## 12. 어떤 예제로 테스트할 수 있나요?

테스트 페이지에서는 다음과 같은 예제를 제공합니다.

| 예제 | 확인할 주요 결과 |
| :--- | :--- |
| 아이그너 니트탑 | 블랙 색상 및 90·95·100·105 사이즈 |
| 리르 패치 | 수량 9개, 개당 수량 50개입 |
| 김소형 선크림 | 수량 7개, 개당 용량 50ml |
| 종가 김치 세트 | 수량 1세트, 개당 중량 5.2kg |
| 해즈픽 칫솔 세트 | 수량 1세트, 개당 수량 10매입 |
| 플럭스 TV | 화면크기 109cm·43인치·109cm(43인치) |

예제에 표시된 값은 해당 상품을 테스트했을 때 **기대하는 결과**입니다.

실제 AI의 응답은 달라질 수 있으므로 최종 결과와 판단 근거를 함께 확인해 주세요.

---

## 13. 결과는 어떻게 확인하나요?

분석이 끝나면 가장 먼저 **최종 단품 결과**를 확인합니다.

이 영역에는 프로그램의 검증까지 완료된 구매옵션 조합이 표시됩니다.

필요한 경우 **AI·서버 판단 및 옵션 매핑 상세**를 펼쳐 AI가 처음 제안한 내용과 프로그램이 해당 결과를 어떻게 판단했는지 확인할 수 있습니다.

### AI 결과와 최종 결과는 다를 수 있습니다

AI가 값을 제안했더라도 프로그램의 검사에서 문제가 발견되면 최종 결과에 사용되지 않을 수 있습니다.

따라서 **AI가 제안한 값보다 최종 단품 결과를 기준으로 확인하는 것이 중요합니다.**

---

## 14. 신뢰도는 어떻게 보면 되나요?

화면에는 AI가 분석 결과를 얼마나 확실하게 판단했는지 참고할 수 있도록 **신뢰도**가 표시됩니다.

예:

```text
신뢰도 85%
```

다만 이 숫자를 실제 정답 확률로 해석하면 안 됩니다.

예를 들어 신뢰도 `95%`가 표시되었다고 해서 **실제 정답일 확률이 정확히 95%라는 의미는 아닙니다.**

AI가 자신의 판단에 대해 부여한 참고 값입니다.

따라서 신뢰도 숫자만 확인하기보다는 다음 내용을 함께 확인하는 것이 좋습니다.

- 최종 단품 결과
- 검토 필요 여부
- AI·서버 판단 사유
- 옵션 매핑 결과

신뢰도가 낮더라도 결과 자체에 문제가 없다면 추가 분석을 하지 않을 수 있습니다.

반대로 신뢰도가 높더라도 프로그램 검증에서 문제가 발견되면 최종 결과로 사용되지 않을 수 있습니다.

---

## 15. `자동 적용 후보`는 무엇인가요?

분석 결과가 충분히 명확하고 프로그램의 검증을 모두 통과하면 **자동 적용 후보**로 표시될 수 있습니다.

자동 적용 후보는

> "다음 업무 단계에서 사용할 수 있는 수준으로 판단된 결과"

라는 의미입니다.

**쿠팡 상품에 실제로 자동 등록하거나 수정했다는 의미는 아닙니다.**

현재 서비스는 분석 결과를 제공하는 단계이며 실제 쿠팡 상품 등록·수정은 수행하지 않습니다.

---

## 16. AI 사용량과 예상 비용 확인

실제 AI 분석을 사용한 경우 **AI 호출·토큰 사용량**을 펼쳐 이번 요청에서 사용한 AI 정보를 확인할 수 있습니다.

주요 항목은 다음과 같습니다.

| 표시 항목 | 의미 |
| :--- | :--- |
| 분석 방식 | 이번 요청에 사용한 분석 방식 |
| 모델 | 실제 사용한 AI 모델 |
| 입력 토큰 | 상품 정보 등을 AI에게 전달하는 데 사용된 양 |
| 출력 토큰 | AI가 결과를 만드는 데 사용한 양 |
| 총 토큰 | 전체 사용량 |
| 예상 비용 | 사용량을 기준으로 계산한 예상 비용 |

첫 번째 분석에서 문제가 발견되어 한 번 더 상세하게 분석한 경우에는 **두 번의 AI 사용량이 각각 표시되고 전체 합계도 제공됩니다.**

화면에 표시되는 비용은 예상 금액이며 실제 청구 금액과 차이가 있을 수 있습니다.

테스트 모드에서는 실제 AI를 사용하지 않으므로 AI 사용 비용이 발생하지 않습니다.

---

## 17. AI 호출 이력은 자동으로 기록됩니다

실제 AI 분석을 실행하면 다음과 같은 정보가 서버에 자동으로 기록됩니다.

- 호출 시각
- 상품 ID
- AI 사용량
- 처리 시간
- 처리 결과

사용자가 별도로 저장할 필요는 없습니다.

이 기록은 **AI 사용량과 예상 비용 확인, 오류 발생 시 원인 확인** 등에 사용됩니다.

상품정보고시 전체 내용이나 API 키와 같은 정보는 호출 이력에 기록하지 않습니다.

기본 보관 기간은 30일이며 운영 환경 설정에 따라 달라질 수 있습니다.

분석에 문제가 발생하여 담당자에게 문의할 때는 가능하면 다음 정보를 함께 전달해 주세요.

**상품 ID + 실행 시각 + 화면에 표시된 오류 또는 판단 사유**

이 정보를 전달하면 담당자가 해당 분석 이력을 찾는 데 도움이 됩니다.

---

## 18. 결과가 나오지 않거나 `검토 필요`가 표시되면?

먼저 화면에 표시된 **판단 사유**와 **확인할 항목**을 확인해 주세요.

그다음 입력한 내용을 다음 순서로 확인하는 것을 권장합니다.

1. 원본 단품 옵션명이 정확한지 확인합니다.
2. 단품이 빠지거나 중복 입력되지 않았는지 확인합니다.
3. 필요한 쿠팡 구매옵션명이 모두 입력되어 있는지 확인합니다.
4. SK스토아 상품정보고시가 올바르게 입력되어 있는지 확인합니다.
5. 수량·용량 상품이라면 상품 기술서·구성이 충분한지 확인합니다.
6. 단위를 사용하는 옵션이라면 단위 설정이 올바른지 확인합니다.

입력 내용을 수정할 부분이 있다면 수정한 후 다시 분석해 주세요.

입력에는 문제가 없어 보이지만 계속 결과를 얻을 수 없다면 담당자에게 다음 정보를 전달해 주세요.

```text
상품 ID
실행 시각
입력한 원본 옵션명
화면에 표시된 판단 사유 또는 오류 내용
```

## 19. 사용할 때 기억할 점

이 서비스는 AI가 상품 옵션 분석을 **도와주는 서비스**입니다.

특히 다음 사항을 기억해 주세요.

- AI가 제안한 값보다 **최종 단품 결과**를 우선해서 확인합니다.
- 신뢰도는 실제 정답 확률을 의미하지 않습니다.
- 상품정보고시에 있다고 해서 원본 옵션명에 없는 색상이나 사이즈를 임의로 추가하지 않습니다.
- 수량이나 상품 구성이 불명확하면 AI가 값을 임의로 만들기보다 **검토 필요**로 표시할 수 있습니다.
- 테스트 모드는 실제 AI 정확도를 확인하는 기능이 아닙니다.
- 실제 AI 분석에는 API 사용 비용이 발생합니다.
- `자동 적용 후보`라고 표시되어도 실제 쿠팡 상품이 등록되거나 수정되는 것은 아닙니다.
- 현재 단계에서는 **최종 적용 전에 운영 담당자가 결과를 확인하는 것을 권장합니다.**
