구매옵션 매핑 API

SK스토아 상품과 단품 옵션을 입력해 쿠팡 구매옵션명을 리턴하는 API 입니다.

사용설명서 API 명세서 API 내부 설계/운영
01

상품 정보

상품 기술서 · 구성 (선택)
02

스토아 단품 옵션

입력하지 않으면 단일상품으로 처리합니다.

단품 ID원본 옵션명삭제
최대 200개 · 단품 ID는 자동 증가하며 수정할 수 있습니다. · 옵션명 예: 블랙/90
03

쿠팡 구매옵션명

실제 쿠팡 카테고리에서 허용한 구매옵션을 입력하세요.

구매옵션명 *기본단위 (선택)단위 선택지 (선택)삭제
1~200개 · 한 행에 구매옵션명 하나를 입력하세요. 단위가 필요한 항목만 기본단위와 선택지를 모두 입력하세요.

색상·사이즈처럼 단위가 필요 없는 항목은 이름만 입력하세요. 단위 선택지는 쉼표로 구분합니다.
AI는 원문에 맞는 단위를 선택하며, 선택지에서 고를 수 없으면 기본단위를 사용합니다.
