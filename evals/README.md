# 검토한 평가 결과

이 폴더는 사람이 검토한 사례의 입력, 원본 기준값, 검토·확정값과 연결된 실행 결과를 Git으로 관리한다. 성공 확인뿐 아니라 개선 필요·등록값 확인 필요도 포함한다. 검토를 초기화한 사례는 다음 내보내기에서 제외된다.

로컬 서버를 새 코드로 재시작한 뒤 프로젝트 루트에서 실행한다.

```powershell
.\scripts\export-evaluation.ps1
# 특정 데이터 세트 선택
.\scripts\export-evaluation.ps1 -DatasetId '<데이터 세트 ID>'
```

기본 출력은 `evals/stoa-reviewed.json`이다. 같은 데이터 세트를 같은 경로로 내보내면 Git diff에서 변경을 비교할 수 있다. 화면의 **검토 결과 내보내기 (Git)**으로 받은 JSON을 이 폴더에 저장해도 된다. 내보내기는 AI를 호출하지 않는다. JSON에는 상품 원문·응답·검토 메모가 포함되므로 커밋 전 내용을 확인한다. API 키나 환경 설정은 포함하지 않는다.

`formatVersion: 1`의 `source`는 원본 데이터 세트 정보, `cases[].testCase`는 입력·기준 행, `reviews`는 현재 검토, `runs`는 최근 실행 및 검토가 참조하는 실행이다. 실행 응답에 기록된 프롬프트 버전·입력 해시·사용량을 함께 보존한다. 내보낸 시각을 별도로 넣지 않아 변경 없는 내보내기에서 불필요한 차이를 만들지 않는다.

전체 실행·검토 변경 이력의 서버 간 이전은 **데이터 백업** ZIP을 대상 서버의 **데이터 새로 가져오기**에서 업로드한다. JSON은 비교용이며 복원 입력은 ZIP이다. Git 커밋이나 배포만으로 운영 데이터가 자동 갱신되지는 않는다. 전체 이력과 원본 Excel은 기존 `data/` 또는 비공개 Blob 저장소에 보관한다.
